HOSTINGER DEPLOYMENT STEPS:
========================================

OPTION 1: Via File Manager (Recommended)
-----------------------------------------
1. Login to your Hostinger control panel (hPanel)
2. Navigate to "File Manager"
3. Go to the "public_html" directory
4. DELETE all existing files in public_html (backup first if needed)
5. UPLOAD all files from "Final V2 Live" folder to public_html
   - Upload index.html
   - Upload the entire "assets" folder
   - Upload image.png
   - Upload manifest.json, robots.txt, sitemap.xml
6. Verify the file structure looks like:
   public_html/
   ├── index.html
   ├── assets/
   │   ├── finallogocs-D26q6HJy.png
   │   ├── index-B30wkE4Q.css
   │   ├── index-BGNDbQUS.js
   │   ├── react-vendor-CvhhSHw0.js
   │   └── ui-vendor-Kyk1uK8q.js
   ├── image.png
   ├── manifest.json
   ├── robots.txt
   └── sitemap.xml
7. Visit your website URL to verify it's live

OPTION 2: Via FTP (Alternative)
--------------------------------
1. Use an FTP client (FileZilla recommended)
2. Connect using your Hostinger FTP credentials
3. Navigate to /public_html/
4. DELETE all existing files (backup first if needed)
5. UPLOAD all files from "Final V2 Live" folder
6. Verify file structure (same as above)
7. Visit your website to confirm

OPTION 3: Via ZIP Upload (Fastest)
-----------------------------------
1. Login to Hostinger hPanel
2. Go to File Manager
3. Navigate to public_html
4. DELETE all existing files
5. UPLOAD the "Final_V2_Live.zip" file
6. RIGHT-CLICK the zip file and select "Extract"
7. DELETE the zip file after extraction
8. Visit your website to verify
